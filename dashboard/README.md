# Dashboard EcoEnergy Analytics

## Visualização dos resultados

Como etapa final do projeto, os resultados obtidos durante a análise exploratória foram apresentados em um dashboard desenvolvido no **Google Looker Studio**.

O dashboard tem como objetivo facilitar a interpretação dos resultados por meio de indicadores, gráficos, comparações temporais e análise entre países.

## Principais visualizações

O dashboard está organizado em três páginas principais.

### 1. Visão Geral

Apresenta:

- participação média das energias renováveis;
- participação média dos combustíveis fósseis;
- participação média da energia hidrelétrica;
- participação média da energia solar;
- participação média da energia eólica;
- evolução temporal das energias renováveis;
- comparação entre renováveis e combustíveis fósseis;
- evolução das principais fontes renováveis.

### 2. Comparação Internacional

Apresenta:

- comparação da participação das energias renováveis entre países;
- comparação entre fontes renováveis e combustíveis fósseis;
- mapa da participação das energias renováveis;
- análise dos dados disponíveis para 2025.

### 3. Brasil

Apresenta:

- participação das energias renováveis;
- participação da energia hidrelétrica;
- participação da energia solar;
- participação da energia eólica;
- evolução das renováveis e dos combustíveis fósseis;
- evolução das principais fontes renováveis;
- diferença entre a participação de renováveis e fósseis.

## Principais resultados apresentados

A análise identificou uma participação média de aproximadamente:

| Indicador | Média |
|---|---:|
| Energias renováveis | 29,99% |
| Combustíveis fósseis | 64,95% |
| Hidrelétrica | 25,09% |
| Solar | 1,12% |
| Eólica | 1,71% |

Também foi observada uma evolução da participação das energias renováveis ao longo do período analisado.

Entre 1985–1999, a participação média das renováveis foi de aproximadamente **25,75%**.

Entre 2020–2025, esse valor passou para aproximadamente **36,68%**.

No mesmo intervalo, a participação média da energia solar aumentou de aproximadamente **0% para 4,70%**, enquanto a energia eólica passou de aproximadamente **0,05% para 4,84%**.

## Ferramentas utilizadas
