# EcoEnergy-Analytics
Projeto de análise de dados sobre a participação das energias renováveis na geração de eletricidade.

# Dashboard EcoEnergy Analytics

O dashboard apresenta os principais resultados obtidos
na análise dos dados de energia.

## Ferramenta

Google Looker Studio.

## Visualizações

- Indicadores gerais de energias renováveis;
- Evolução temporal;
- Comparação entre energias renováveis e fósseis;
- Comparação entre países;
- Análise específica do Brasil;
- Participação das fontes hidrelétrica, solar e eólica.

## Fonte dos dados

Our World in Data (OWID).
